为什么选择 GH Artifact Proxy？

极速传输 · 全球 Anycast

依托全球分布式边缘加速节点与优质链路，彻底告别 Artifact 下载超时与断连。

安全透明 · 零数据截留

端到端 HTTPS 双向加密代理，纯流式转发，不篡改、不缓存、不留存任何构建产物。

全场景覆盖 · 即开即用

公有仓库代理加速、私有仓库 Token 直连、大文件流式进度，无需安装任何客户端。

多代理调度 · 一键切换

内置多个社区加速节点并支持自定义代理，失效时随手切换，复制链接即走 wget / curl。

如何使用

  1. 打开 GitHub Actions 的 Workflow Run 页面，复制浏览器地址栏中的链接；
  2. 粘贴到上方输入框，点击「解析」（粘贴完整链接时会自动开始）；
  3. 在 Artifact 列表中点击「下载」，或点「复制链接」用 wget / curl / 下载工具下载。

提示：私有仓库请在高级选项中填写具备 repo 权限的 Token；Artifact 默认保留 90 天，过期后不可下载。 如果代理下载失败，可依次尝试其他代理、切换下载方式，或改用 gh run download <run-id> -R owner/repo。
